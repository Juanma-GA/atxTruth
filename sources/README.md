# sources/ — material de partida (solo lectura)

Ficheros de referencia que entrega Juanma. **No se modifican**: la app los usa como modelo de formato
o como datos de prueba (todos los datos son sintéticos).

| Carpeta | Fichero | Para qué sirve |
|---|---|---|
| `templates/` | `Refs.pptx` | Formato y estilos de la slide de referencia de proyecto (caso 2). Hoy usa marcadores de layout, no etiquetas. |
| `templates/` | `Template_for_Blocks.pptx` | Formato y estilos de las slides de bloque del catálogo (caso 1). Lleva etiquetas `{{Hoja!Celda}}` de un script antiguo. |
| `templates/` | `catalogue_report_template.html`, `catalogue_processes.html` | Formato y estilos del informe HTML del catálogo (caso 1). |
| `excel/` | `CS_Reference_Template_v0.6.xlsx` | Referencias de proyecto (hoja `References`, 2 filas de ejemplo) y listas de valores (hoja `Lists`, taxonomía Catálogo V0). |
| `excel/` | `CCX_Customer_Services_Offer_Catalogue_V0.1.xlsx` | Catálogo de servicios (caso 1). |
| `design/` | `mockup_look_and_feel.html`, `alten_logo.png` | Look & feel de la app (paleta, tipografía, layout) y logo. El mockup es de otra app: se copia el estilo, no las funciones. |
| `examples/` | `generar_slides.py`, `generar_informe.py` | Scripts antiguos de ejemplo. **Solo orientativos**: lo que vale es el formato de las plantillas, no su forma de volcar los datos. |
